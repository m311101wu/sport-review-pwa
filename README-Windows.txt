運動復盤｜Windows 免安裝可攜版

使用方式
1. 將整個資料夾複製到 Windows 電腦。
2. 雙擊「開始運動復盤.bat」。
3. 建議使用最新版 Microsoft Edge 或 Google Chrome。
4. 在網頁中選擇手機影片開始復盤。

本版本不需要安裝 Node.js、Python 或其他套件。
影片與分析資料只在本機瀏覽器處理，不會自動上傳。

目前保留功能
- 手動左右腳點地／離地標記
- 鍵盤方向鍵逐幀與腳部標記
- 剪輯式時間軸、縮放、拖曳播放頭
- 音訊波形與跑台節奏分析
- 左右腳交替時間、前中後三期統計
- 完整分析 CSV 匯出
- 角度、箭頭、線條與比例校正

目前刻意移除
- 自動姿勢／骨架分析模型

注意
- 請不要只複製 .bat，必須保留同一資料夾內的 index.html、app.js、styles.css。
- 若 Windows 顯示安全警告，請確認檔案來源後選擇保留／仍要執行。
- 若影片音訊無法解碼，仍可使用影片播放與手動標記功能。
